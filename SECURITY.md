# Security Policy

## Supported Versions

Security fixes are provided for the latest released version in the `0.1.x`
series. Please upgrade to the latest available release before reporting an
issue.

| Version | Supported |
| ------- | --------- |
| Latest `0.1.x` release | :white_check_mark: |
| Earlier releases | :x: |

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately by email to
[dev@insysbio.com](mailto:dev@insysbio.com). Do not report them in public
GitHub issues, discussions, pull requests, or commits.

Include a clear description of the issue, affected versions, steps to
reproduce it, and any proof-of-concept code or files that can be shared
safely.

We will acknowledge receipt within 5 business days and provide a status update
at least every 14 days while the report is under review. If the issue is
accepted, we will work on a fix and coordinate disclosure with the reporter.
If it is declined, we will explain why.
